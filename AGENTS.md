# AGENTS.md

Always-on правила для агентов в `kino-pub-improve`.

## Язык

Всегда отвечай пользователю **на русском**. Это жёсткое правило для чата, пояснений и описаний PR. Сообщения коммитов — на английском, в стиле текущего git-лога.

Не переводить:

- код, идентификаторы, команды, логи и цитаты из источника;
- пути и имена файлов.

UI-строки расширения пиши на русском, как в текущем проекте.

## Как работать

- Читай этот файл в начале задачи и следуй ему.
- Если есть `docs/agents/` — открывай нужный runbook только когда реально работаешь с этой темой.
- Следуй паттернам репозитория и переиспользуй существующие модули (`lib/`, popup, options, sidepanel, content-scripts).
- Минимальный дифф: без несвязанных правок, рефакторинга «заодно» и новых файлов/доков без нужды.
- Не запускай `npm test`, `npm run typecheck`, `npm run pack` и прочий build/test/lint без явной просьбы.
- Не коммить и не пушь без явной просьбы.
- В ответах указывай **полный абсолютный путь** к файлам (`/workspace/...` в Cloud Agent, диск/корень на локальной машине). Не пиши относительные пути без корня.

## Skills

Если в ходе задачи появился повторяемый паттерн, pitfall, API, workflow или CLI — сразу обнови skill/rule в `.cursor/` в том же заходе. Не жди отдельной просьбы.
